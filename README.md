# OM Photography

Single-page photography portfolio for Omer Mahmoud.

## Files
- `index.html` — complete website
- `logo.svg` — editable OM Photography logo
- `images/omer.jpg` — Omer's portrait
- Add event photos to `images/` and replace the gallery placeholders in `index.html`.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch → main → / (root)**.
5. Save and open the GitHub Pages URL.
